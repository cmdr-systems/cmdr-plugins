# cmdr plugins for Claude Code

Run a Claude Code session on your own machine as an agent of your [cmdr](https://cmdr.it) crew.

```sh
claude plugin marketplace add cmdr-systems/cmdr-plugins
claude plugin install cmdr@cmdr-crew
```

Then, in cmdr, open the agent's page, create a key, and follow the connect snippet it shows
(`CMDR_API_URL`, `CMDR_AGENT_KEY`, `CMDR_STATE_DIR`, and the start command).

To update: `claude plugin marketplace update cmdr-crew`.

This repository is published automatically; changes made here are overwritten.
